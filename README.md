# Calculadora de Horas Anuales CGT

Herramienta informativa de CGT Primark Gran Vía (Madrid) para consultar la referencia anual de jornada de 2026, la distribución irregular indicada en el cartel y la estimación proporcional entre fechas.

Se utiliza directamente desde `index.html`. Los cálculos se realizan en el navegador; no se solicitan nombres, no se cargan rotas ni existe una base de datos de trabajadores.

**Aviso:** Los resultados son orientativos. Vacaciones, bajas, permisos, festivos, cambios de contrato y calendario laboral pueden modificar el cómputo individual. No se debe interpretar una diferencia como deuda de horas.

Proyecto: Víctor Llantoy Cáceres · CGT Primark Gran Vía.
